## ✨ Features & Engineering Highlights

* 🎨 **Stripe / Linear / Apple Design Aesthetic**:
  * Glassmorphism cards, glowing border highlights, and refined typography.
  * Dark mode by default with a clean, high-contrast Light mode toggle.
  * Theme preference stored and persisted in `localStorage`.
* ⚡ **Zero-Dependency Vanilla Architecture**:
  * Built using pure HTML5, CSS3, and modern Vanilla JS (zero bundlers, zero npm dependencies).
  * Interactive HTML5 `<canvas>` particle network background.
  * Smooth typewriter effect for role rotations.
  * Animated number counters triggered via `IntersectionObserver`.
* 📁 **Comprehensive Sections**:
  1. **Hero Section**: Dynamic typing animation, status pill, quick stats row, and interactive code terminal.
  2. **About Me**: Professional philosophy, engineering mindset, key pillars, and career summary.
  3. **Technical Skills**: Categorized into 6 interactive competency cards with skill badges.
  4. **Experience Timeline**: Vertical animated timeline detailing Cognizant GenAI CoE, Cognizant Oracle BU, Boeing, and Accenture.
  5. **Featured Projects**: Filterable project gallery with interactive modal deep-dive dialogs.
  6. **Verified Statistics**: Key metrics (11+ yrs, 2000+ automated tests, 40% CI/CD speedup, 4 enterprise giants).
  7. **Certifications & Honors**: MIT-ASDA, IBM Java, Google Python, Postman v12, Boeing Pride Award, Cognizant Asset Creation.
  8. **Education**: IIT Jodhpur (M.Tech AR/VR) and GNIOT (B.Tech CSE).
  9. **Peer Endorsements**: Recommendations from AI Architects and Engineering Managers.
  10. **Resume & Contact**: Downloadable CV callout, copy-to-clipboard utilities, and contact form with instant validation.

## 🚀 Instant Deployment on GitHub Pages

1. Commit and push the `portfolio/` folder to your GitHub repository:
   ```bash
   git add portfolio/
   git commit -m "Add world-class portfolio website"
   git push origin main
   ```
2. Enable GitHub Pages in your repository **Settings** ➔ **Pages** (set to `main` branch root).
3. Access your live portfolio at:
   `https://<YOUR-USERNAME>.github.io/Fun_projects/portfolio/`
