## ✨ Features & Architecture Highlights

* 🎨 **Stripe / Linear / Apple Design Aesthetic**:
  * Glassmorphism cards, glowing border highlights, and refined typography.
  * Dark mode by default with a clean, high-contrast Light mode toggle.
  * Theme preference stored and persisted in `localStorage`.
* ⚡ **Zero-Dependency Vanilla Architecture**:
  * Built using pure HTML5, CSS3, and modern Vanilla JS (zero bundlers, zero npm dependencies).

## 🚀 Instant Deployment on GitHub Pages

1. Commit and push the `portfolio/` folder to your GitHub repository:
   ```bash
   git add portfolio/
   git commit -m "Update portfolio technical showcase"
   git push origin main
   ```
2. Enable GitHub Pages in your repository **Settings** ➔ **Pages** (set to `main` branch root).
3. Access your live showcase at:
   `https://<YOUR-USERNAME>.github.io/Fun_projects/portfolio/`
