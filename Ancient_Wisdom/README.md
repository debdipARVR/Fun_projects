## 🚀 How to Deploy on GitHub in 60 Seconds

1. **Create a new GitHub repository** (e.g., `universal-wisdom-protocol`).
2. **Upload all files** from this folder to the repository root:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: Universal Wisdom Protocol suite"
   git branch -M main
   git remote add origin https://github.com/<YOUR-USERNAME>/<YOUR-REPO>.git
   git push -u origin main
   ```
3. **Enable GitHub Pages**:
   - Go to your repo **Settings** ➔ **Pages**.
   - Under **Build and deployment** ➔ **Source**, select **GitHub Actions** (or select `Deploy from a branch` ➔ `main` ➔ `/ (root)`).
4. Your site is live immediately at:
   `https://<YOUR-USERNAME>.github.io/<YOUR-REPO>/`

## 🖨️ How to Print Reflection Slips onto Colored A4 Paper

1. Open [`printable-slips.html`](printable-slips.html).
2. Click any color category (e.g. **`🔵 Calming Worry`**).
3. Load colored A4 paper sheets into your printer.
4. Press **`Ctrl + P`** (Print).
5. Cut along the dotted scissor lines to get uniform cards ready for daily jars!
